# Vuelta a Colombia - Database System

Sistema de gestión logística para la Vuelta a Colombia desarrollado en Python con PyQt5 y SQLite.

## Características

- Agregar ciclistas
- Consultar información con filtros dinámicos
- Eliminar registros
- Actualizar nacionalidad
- Interfaz gráfica intuitiva

## Tecnologías

- Python 3
- PyQt5
- SQLite3

## Estructura

El sistema implementa un CRUD completo sobre una base de datos SQLite local.

## Cómo ejecutar

```bash
pip install -r requirements.txt
python main.py
